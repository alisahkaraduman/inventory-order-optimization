# Inventory & Order Optimization System

A PostgreSQL-based inventory and order management system designed to track stock movements, manage orders, analyze inventory performance, and support replenishment decisions.

## Project Goal

The goal of this project is to build a structured inventory management database and generate useful operational insights from historical stock and order data.

## Main Features

- PostgreSQL database design
- Inventory and stock transaction management
- Trigger-based stock updates
- Transaction management
- Views and reporting queries
- Reorder point calculation
- Safety stock analysis
- ABC inventory analysis
- KPI-based inventory evaluation
- Query performance analysis with indexes
